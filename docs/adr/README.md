# Architecture decision records

One file per accepted decision. **None recorded yet.**

Write an ADR when a decision has trade-offs and would otherwise be re-litigated or silently
reversed. Routine choices that follow existing patterns don't need one.

**Naming**: `NNNN-short-title.md`, zero-padded and sequential, e.g. `0001-content-source.md`.

**Structure**: Title / Status (proposed, accepted, superseded by NNNN) / Date / Context / Decision /
Consequences.

Keep superseded ADRs in place and mark their status; the record of what was decided and later
changed is the point. Decisions still unmade belong in `docs/project/open-questions.md`, not here.
